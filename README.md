# Restaurant-3JS

A simple 3D visualization of a little restaurant built with Three.js.

## Description

This project renders a 3D model of a restaurant scene, allowing users to orbit around the scene using mouse controls. The model is loaded from a GLTF file and textured with a baked texture for efficient rendering.

## Features

- 3D restaurant model
- Orbit controls for navigation (zoom, pan, rotate)
- Responsive design
- Baked textures for performance

## Usage

Simply open `index.html` in a modern web browser. The scene will load and you can interact with it using your mouse.

## Technologies

- [Three.js](https://threejs.org/) - 3D JavaScript library
- GLTFLoader - For loading 3D models
- OrbitControls - For camera controls
